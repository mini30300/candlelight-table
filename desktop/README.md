# Candlelight Table บนคอม (.exe)

หน้าต่างเดียวที่เปิด `https://candlelight-table.mini3030023450.workers.dev/app`
ซึ่งเป็นตัวเกมทั้งหมด (ล็อกอิน เลือกโต๊ะ กระดานสามมิติ ลูกเต๋า) เสิร์ฟจาก Worker ตัวเดียวกับที่มือถือใช้
ฝั่ง Rust จึงมีแค่ `main.rs` สิบบรรทัด — อัปเดตหน้าเว็บบนเซิร์ฟเวอร์แล้วแอพบนคอมได้ของใหม่ทันที ไม่ต้องลงใหม่

## เอา .exe มาจากไหน

GitHub Actions สร้างให้ทุกครั้งที่ push เข้า `main` (ดู `.github/workflows/build.yml` job `windows-release`)
ในหน้า Releases จะมีสองไฟล์

| ไฟล์ | คืออะไร |
| --- | --- |
| `Candlelight Table_1.0.0_x64-setup.exe` | ตัวติดตั้ง ลงแล้วมีไอคอนใน Start menu |
| `candlelight-table.exe` | ตัวเปล่า ก๊อปไปวางที่ไหนก็กดเปิดได้เลย ไม่ต้องติดตั้ง |

ต้องมี **WebView2** ในเครื่อง — Windows 10 และ 11 มีมาให้อยู่แล้ว ถ้าไม่มี ตัวติดตั้งจะโหลดให้เอง

## เชื่อมกับมือถือ

ในแอพมือถือ → หน้า “จะเล่นอะไรดี” → **เล่นบนคอมด้วย** → แตะเพื่อขอรหัส
แล้วเอารหัส 8 ตัวไปใส่ในคอม (ช่อง “รหัสจับคู่” ที่หน้าล็อกอิน) คอมจะเข้าบัญชีเดียวกัน
เห็นโต๊ะเดียวกัน และใครทอยเต๋าอีกฝั่งก็เห็นลูกเต๋ากลิ้งบนโต๊ะเหมือนกัน
รหัสมีอายุ 5 นาที ใช้ได้ครั้งเดียว

ถ้าอยากเล่นบนคอมโดยไม่ลงอะไรเลย เปิด `/app` ในเบราว์เซอร์ก็ได้ เหมือนกันทุกอย่าง

## สร้างเองบนเครื่อง Windows

```
cd desktop
npx @tauri-apps/cli@2 build
```

ไอคอนสร้างจากสคริปต์ ไม่ได้วาดมือ แก้สีหรือรูปทรงได้ใน `make-icons.py` แล้วสั่ง

```
python3 desktop/make-icons.py
```
