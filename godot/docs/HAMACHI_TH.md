# เล่นกับเพื่อนต่างบ้านผ่าน Hamachi (เหมือนเล่น Minecraft)

ปกติ "เล่นกับเพื่อน" ใช้ได้เฉพาะเครื่องที่อยู่ Wi-Fi เดียวกัน รุ่นนี้เล่นกับเพื่อนที่อยู่คนละบ้านได้แล้ว
โดยให้ทุกคนเข้าเครือข่าย Hamachi เดียวกันก่อน แอปจะมองว่าอยู่ "บ้านเดียวกัน"

## ก่อนเริ่ม

- ทุกคนต้องใช้ **แอปโต๊ะเทียนตัวปกติ รุ่นเดียวกัน** (ดูเลขรุ่นที่หน้าแรก) ถ้ารุ่นไม่ตรง แอปจะบอกว่า "รุ่นแอปไม่ตรงกัน"
- **แอปส่วนตัวของมินิห้ามส่งให้ใคร** มินิเปิดแอปส่วนตัวเป็นเจ้าห้องได้ แต่เพื่อนต้องใช้แอปตัวปกติ
- Hamachi ใช้บนคอมพิวเตอร์ (Windows) รุ่นฟรีเข้าได้ 5 เครื่องต่อเครือข่าย
- ถ้าเพื่อนใช้มือถือ Android ใช้โปรแกรม Tailscale แทน Hamachi ได้ (ขั้นตอนเหมือนกัน) หรือคอมใช้ Radmin VPN ก็ได้
  ขอแค่ทุกคนใช้โปรแกรมเดียวกัน

## ขั้นตอน

1. **ทุกเครื่องติดตั้ง Hamachi** (LogMeIn Hamachi) แล้วเปิดโปรแกรม กดปุ่มเปิดเครื่อง (ปุ่มพาวเวอร์) ให้เป็นสีน้ำเงิน
2. **เข้าเครือข่ายเดียวกัน**
   - เจ้าห้อง: เมนู Network → Create a new network → ตั้งชื่อเครือข่ายกับรหัสผ่าน
   - เพื่อน: เมนู Network → Join an existing network → ใส่ชื่อเครือข่ายกับรหัสผ่านเดียวกัน
   - ในหน้าต่าง Hamachi จะเห็นชื่อเพื่อนเป็นจุดสีเขียว = ต่อกันแล้ว
3. **เจ้าห้องเปิดห้อง**: เปิดแอปโต๊ะเทียน → เดินไปที่ประตูเทียบยาน (หรือกด ออนไลน์ ที่หน้าแรก) → กด **เปิดห้อง**
   - บนการ์ดห้องจะมีบรรทัด **"IP VPN ของเครื่องนี้ (Hamachi): 25.x.x.x"**
   - กด **คัดลอก IP VPN** แล้ววางส่งให้เพื่อนทางไลน์ (เลข 25.x นี้ตรงกับเลขบนสุดของหน้าต่าง Hamachi)
4. **เพื่อนต่อเข้าห้อง**: เปิดแอปโต๊ะเทียน → ประตูเทียบยาน → ช่อง **"ใส่ IP ของเจ้าห้อง"** ใส่เลข 25.x ของเจ้าห้อง →
   กด **ต่อด้วย IP**
   - ห้องจะไม่ขึ้นเองในรายการ "ห้องที่พบใน Wi-Fi เดียวกัน" ต้องพิมพ์ IP ทุกครั้ง
5. **ไฟร์วอลล์ของ Windows**: ครั้งแรกที่กดเปิดห้องหรือต่อด้วย IP จะมีหน้าต่างถามขึ้นมา
   ให้ติ๊ก **"ส่วนตัว (Private)"** แล้วกด **อนุญาต (Allow access)** — ต้องทำ **ทั้งสองเครื่อง**
   - Windows มักนับการ์ด Hamachi / Radmin VPN เป็น "เครือข่ายสาธารณะ" ทำให้ต่อไม่ติด วิธีที่ปลอดภัยคือ
     **ตั้งการ์ด VPN ให้เป็นเครือข่ายส่วนตัว**: เปิด Settings → Network & internet → Advanced network settings →
     เลือกการ์ด Hamachi (หรือ Radmin VPN) → Network profile type → **Private**
     (ถ้าไม่มีตัวเลือกนี้: เปิด PowerShell แบบ Run as administrator แล้วพิมพ์
     `Set-NetConnectionProfile -InterfaceAlias "Hamachi" -NetworkCategory Private` — เปลี่ยน "Hamachi" เป็นชื่อการ์ดของเครื่องนั้น)
   - **อย่าติ๊ก "สาธารณะ (Public)"** เพื่อแก้ปัญหานี้: ถ้าติ๊กแล้วเปิดห้องตอนต่อ Wi-Fi ร้านกาแฟ / โรงแรม คนแปลกหน้าใน Wi-Fi
     นั้นก็เห็นห้องได้ ถ้าเคยติ๊กไว้แล้ว อย่าเปิดห้องบน Wi-Fi สาธารณะ

## ถ้าต่อไม่ได้

| ข้อความในแอป | แก้อย่างไร |
| --- | --- |
| เครื่องนี้ยังไม่ได้ต่อ Hamachi — … | เครื่องนี้ยังไม่ได้เปิด Hamachi หรือยังไม่ได้เข้าเครือข่าย: เปิด Hamachi กดปุ่มพาวเวอร์ แล้วเข้าเครือข่ายเดียวกับเจ้าห้อง |
| ต่อไม่ได้ — เช็กว่าอยู่ Wi-Fi หรือ VPN เดียวกัน … | ส่วนใหญ่เป็นเพราะไฟร์วอลล์ของเจ้าห้อง: ดูข้อ "ลืมกดอนุญาต" ด้านล่าง / เช็กว่าเจ้าห้องยังเปิดห้องอยู่ / เช็กเลข IP ว่าพิมพ์ถูก |
| รุ่นแอปไม่ตรงกัน … | อัปเดตแอปให้เป็นรุ่นเดียวกันทุกเครื่อง |
| ห้องเต็มแล้ว | ห้องหนึ่งเล่นได้สูงสุด 6 คน |

**ลืมกดอนุญาตไฟร์วอลล์ (หรือเผลอกดยกเลิก):** เปิด Windows Security → Firewall & network protection →
Allow an app through firewall → Change settings → หา **Candlelight Table** (หรือ CandlelightTable.exe) →
ติ๊ก Private → OK แล้วลองใหม่ (ถ้ายังต่อไม่ติด ให้ตั้งการ์ด VPN เป็นเครือข่ายส่วนตัวตามข้อ 5)

## เรื่องความปลอดภัย

- ใครก็ตามที่อยู่ในเครือข่าย Hamachi เดียวกันเข้าห้องได้ (เหมือนคนที่อยู่ Wi-Fi ร้านกาแฟเดียวกัน)
  **ให้รหัสผ่านเครือข่ายเฉพาะเพื่อนที่รู้จัก** อย่าเข้าเครือข่ายสาธารณะของคนแปลกหน้า
- แอปรับเครื่อง 25.x เฉพาะตอนที่เครื่องเจ้าห้องเองก็อยู่ใน Hamachi ด้วย คนนอกบนอินเทอร์เน็ตต่อเข้ามาไม่ได้
