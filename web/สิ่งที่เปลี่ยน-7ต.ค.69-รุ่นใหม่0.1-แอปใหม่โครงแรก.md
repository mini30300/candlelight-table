# สิ่งที่เปลี่ยน 7 ต.ค. 69 — แอปใหม่ รุ่นใหม่ 0.1 โครงแรก (ขั้นที่ศูนย์ของแผน)

แอปใหม่ของโต๊ะเทียนที่สร้างด้วย Godot 4 ก้อนแรก อยู่ใน PR 27 ของ candlelight-table (โฟลเดอร์ `godot/`)
แอปเดิมไม่ถูกแตะ ยังใช้และออกรุ่นได้ตามปกติ แอปใหม่ติดตั้งคู่กันได้เพราะใช้ชื่อแพ็กเกจคนละชื่อ

## มินิจะเห็นอะไรในรุ่นนี้

1. สนามจริงหนึ่งสนาม มีเนิน ซากตึก ต้นไม้ และอุปกรณ์ 480 ชิ้น
2. ตัวหมาก 400 ตัวจากชุดโมเดลทั้ง 312 แบบ สีของตัวหมากเป็นสีเดิมของมัน สีทีมคือวงแหวนบนพื้นใต้ตัวแต่ละตัว ตามที่มินิขอ
3. หน้าตรวจเครื่อง บอกชื่อการ์ดจอ เฟรมต่อวินาที จำนวนคำสั่งวาด หน่วยความจำ เลือกระดับกราฟิกได้สี่ระดับ (สูง กลาง ต่ำ ต่ำสุด)
   มีปุ่มทดสอบหนักที่เพิ่มตัวหมากอีก 500 ตัว ช่องพิมพ์ชื่อภาษาไทย และปุ่มคัดลอกตัวเลขไว้ส่งให้ผม
4. กล้อง ลากนิ้วเดียวเพื่อเลื่อน สองนิ้วเพื่อหมุนและซูม แตะตัวหมากเพื่อเลือก (บนคอมใช้เมาส์และ WASD)
5. ภาษาไทยทั้งแอป สลับเป็นอังกฤษได้ด้วยปุ่มเดียว

ยังเล่นเกมไม่ได้ในรุ่นนี้ รุ่นนี้มีไว้พิสูจน์ว่าเครื่องของมินิวาดได้ลื่นและสวยพอ ก่อนจะย้ายกติกามาในขั้นถัดไป

## วิธีลอง

ตอนยังเป็น PR: เปิดหน้า Actions ของ candlelight-table เลือกเวิร์กโฟลว์ชื่อ Godot รอบล่าสุดของกิ่ง `claude/new-session-fsucoo`
เลื่อนลงไปที่ Artifacts แล้วโหลด `godot-android` (ไฟล์ APK ทดสอบ) หรือ `godot-windows` (zip ของ Windows มีไฟล์ README ภาษาไทยอยู่ข้างใน)
หลังมินิกดรวม PR 27 เข้า main แล้ว ทุกครั้งที่รวมงาน ระบบจะแนบ APK เซ็นจริงและ zip ของ Windows ไว้ใน release build-N อันเดียวกับแอปเดิม

สิ่งที่อยากได้จากมินิ
1. ภาพหน้าจอหน้าตรวจเครื่องจากมือถือ (ระดับที่แอปเลือกให้เอง แล้วลองกดระดับสูงดูว่าเฟรมตกไหม)
2. ลองกดทดสอบหนัก แล้วบอกว่ายังลื่นไหม เครื่องร้อนไหม
3. พิมพ์ชื่อไทยในช่อง แล้วบอกว่าพิมพ์ได้ไหม
4. ถ้ามีคอมเก่า ลองเปิดไฟล์ Windows ด้วย ถ้าเปิดไม่ขึ้นให้บอก เรามีทางสำรอง

## ข้างในมีอะไร (สำหรับคนทำต่อ)

ตัวแปลงตัวหมากจากโค้ดเดิมเป็นโมเดลสามมิติ 312 ตัว, ตัวนำเข้าที่รวมแต่ละตัวเป็นชิ้นเดียวพร้อมช่องสีสำหรับเพ้นท์ในอนาคต,
แกนคำนวณแบบจำนวนเต็ม (ทุกเครื่องคิดตรงกัน), ตัวตรวจข้อมูล (ชื่อต้องห้าม คำแปลอังกฤษ ลูกเต๋าไม่เกิน 60 ลูก ความลับ),
เกมอ้างอิงจากหน้าเก่า 20 เกมไว้เทียบกติกา, และ CI ที่สร้าง APK กับ .exe ให้เองทุกครั้ง รายละเอียดอยู่ใน `godot/docs/` และ `docs/GODOT.md`

## ทดสอบแล้ว

เทสหน่วย 496 ข้อ, เทสภาพ 3 ชุด (ทุกชุดโมเดล งบวาดต่อระดับกราฟิก หน้าจอไทย/อังกฤษ), ตัวตรวจข้อมูลผ่าน,
CI ผ่านครบทั้ง x86 arm64 Windows (รันเทสในไฟล์ .exe จริง) และ Android, และ APK รุ่นฉากทดสอบเปิดบนมือถือของมินิได้แล้ว

## ลำดับการรวม

PR 27 ของ candlelight-table อย่างเดียว ไม่มีงานฝั่งเซิร์ฟเวอร์ในขั้นนี้
