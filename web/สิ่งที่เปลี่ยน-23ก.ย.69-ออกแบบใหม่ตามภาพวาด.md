# 23 ก.ย. 69 — ออกแบบใหม่ทั้งหมดตามภาพวาด

ทำตามภาพวาดที่มินิส่งมาครบทุกหน้า: เข้าสู่ระบบ → เลือกเกม → ตัวละคร → สร้างห้อง → รอกันที่กองไฟ → แต่งตัว → เล่น และหน้าตั้งค่าโต๊ะรบ

สิ่งที่เปลี่ยนมากที่สุดไม่ใช่หน้าตา แต่คือ **ทุกหน้าจอมีอยู่ที่เดียวแล้ว คือหน้าเว็บ**
คอม มือถือ โปรแกรม Windows และแอพ Android เห็นหน้าเดียวกันหมด ตรงกับที่มินิเขียนไว้ว่า "ทำให้เหมือนกันในโทรศัพท์"

> **ก่อนกด merge อ่านข้อ 15 ก่อน** เพราะต้องกดตามลำดับ
> ข้อ 16 มีสามอย่างที่มินิต้องทำเอง (ผมทำแทนไม่ได้)

## 1. เข้าสู่ระบบ

- คอมกับมือถือหน้าเดียวกัน: เทียน · ปุ่ม Google · ลิงก์ "เข้าเล่นแบบผู้เล่นรับเชิญ" อยู่ใต้ปุ่ม
- **เคยเข้าไว้แล้ว** จะเห็นเทียน + วงหมุน + "กำลังเข้าสู่ระบบ…" ระหว่างเช็กว่าบัญชียังใช้ได้ แล้วไปหน้าเลือกเกมเอง
- ตัวตนหมดอายุ → กลับมาหน้าเข้าสู่ระบบ
- เน็ตหลุดตอนเช็ก → ตัวตนไม่หาย ไปหน้าเลือกเกมพร้อมแถบ "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" และปุ่ม **ลองใหม่**
- "มีรหัสจับคู่เครื่อง?" พับเก็บไว้เล็ก ๆ ใต้ปุ่ม
- เข้าเสร็จแล้วไป**หน้าเลือกเกม** (เดิมเข้าหน้า D&D เลย)

## 2. หน้าเลือกเกม

การ์ดรูปสองใบวางข้างกัน (บนมือถือเรียงบนลงล่าง)

| การ์ด | รูป | กด "สร้างโต๊ะ" แล้ว |
| --- | --- | --- |
| **D&D** | ตัวหมากยืนล้อมกองไฟ | ไปหน้าตัวละคร D&D · ใต้ปุ่มมีรายการ "โต๊ะที่ค้างไว้" กดกลับเข้าได้เลย |
| **TABLETOP** | ทหารชุดเกราะใต้ท้องฟ้าสีฟ้า | เปิดโต๊ะรบเต็มหน้าต่าง |

คำอธิบายใต้ TABLETOP: "จำลองการรบบนโต๊ะสามมิติ — จัดทัพ เลือกจุดลงสนาม แล้วผลัดกันเดินกับยิง เล่นกับบอทได้แม้ไม่มีเน็ต"

**แถวเดียว "เข้าร่วม [รหัส 5 ตัว] →" ใต้การ์ดทั้งสอง** ตามเส้นที่มินิลากโยงไว้ในภาพ — ใส่รหัสห้องแบบไหนก็ได้

- เซิร์ฟเวอร์บอกว่ารหัสนี้เป็นห้องอะไร
- ห้อง D&D → ไปหน้าตัวละคร ใส่รหัสรอไว้ให้แล้ว พร้อมสรุปห้อง เช่น "D&D · ยุคอัศวิน · 2/4 คน"
- โต๊ะรบ → เปิดโต๊ะรบแล้วพาเข้าห้องให้เลย (ถ้าเต็มหรือเริ่มรบไปแล้ว จะบอกใต้ช่อง)
- ไม่มีห้องนี้ → "ไม่พบห้อง XXXXX" ใต้ช่อง

ลิงก์เล็ก "เชื่อมบัญชีกับอีกเครื่อง" อยู่ท้ายหน้า · มุมขวาบนมีชื่อ ประเภทบัญชี และ "ออกจากระบบ"

## 3. หน้าตัวละคร D&D

- ตัวละครของเราหมุนช้า ๆ ตรงกลาง ช่อง **ชื่อ** อยู่ใต้ตัว
- ป้าย **ผม · หน้า · ลำตัว · เสื้อผ้า** ชี้รอบตัว กดแล้วเปิดหน้าแต่งตัวที่หมวดนั้นเลย
- แผง **ห้อง** ด้านขวา: โต๊ะที่ค้างไว้ · ปุ่ม **+ สร้างห้อง** · แถว **รหัส [ ] ▶**
- ใส่รหัสโต๊ะรบในแถวนี้ก็พาไปโต๊ะรบให้เหมือนกัน

## 4. สร้างห้อง

- **คน** แถบเลื่อน 2–6 (เริ่มที่ 4)
- **ยุคตั้งต้น** การ์ด 3 ใบ
- **เหตุการณ์** การ์ด 3 ใบของยุคนั้น แต่ละใบบอก **ระดับ**
- ปุ่ม **เปิดห้อง →** ได้รหัส 5 ตัว แล้วไปกองไฟ

ยุคกับเหตุการณ์ที่มีตอนนี้ (ผมเขียนเนื้อหาเอง แก้ได้ ดูข้อ 13)

| ยุค | ง่าย | กลาง | ยาก |
| --- | --- | --- | --- |
| **ยุคอัศวิน** — อาณาจักร ปราสาท ข่าวลือเรื่องมังกร | คาราวานถูกปล้นกลางป่า | ธิดาเจ้าเมืองหายตัว | มังกรตื่นบนเขาทางเหนือ |
| **ยุคเวทมนตร์** — หอคอยนักเวท มนตร์ที่รั่วไหลได้ | หอคอยขอความช่วยเหลือ | พายุเวทกลืนหมู่บ้าน | ประตูมิติเปิดใต้เมือง |
| **ยุคล่มสลาย** — ค่ายผู้รอดชีวิตกลางซากเมือง | เสบียงในค่ายหมด | เสียงระฆังจากเมืองร้าง | กองทัพไร้วิญญาณเดินทัพ |

การ์ดเหตุการณ์ทุกใบมีคำโปรยหนึ่งบรรทัด เช่น มังกรตื่น: "ควันลอยขึ้นจากยอดเขาเป็นครั้งแรกในรอบร้อยปี"

| ตรงไหน | มีอะไร |

| ซ้าย | ยุค · เหตุการณ์ (พร้อมคำโปรย) · ระดับ · รหัสห้องกับปุ่มคัดลอก |
| กลาง | ตัวละครทุกคนยืนล้อมกองไฟ กล้องหมุนช้า ๆ ลากหมุนเองได้ · ป้ายชื่อใต้ตัว · **YOU** กับลูกศรบนหัวเรา · ติ๊กถูกข้างคนที่พร้อมแล้ว |
| ขวา | P1 P2 P3 … / **YOU** พร้อมไอคอน**จอคอม**หรือ**มือถือ** · สถานะพร้อม · **มงกุฎ**ที่เจ้าของห้อง · ช่อง "ที่ว่าง" |

### สุ่มตัวละคร — เซิร์ฟเวอร์เป็นคนสุ่ม

| เรื่อง | ทำงานยังไง |
| --- | --- |
| ใครสุ่ม | **เซิร์ฟเวอร์**สุ่มเผ่า อาชีพ ค่าพลังให้ตอนเข้าห้อง ผู้เล่นเลือกเองได้แค่ชื่อกับหน้าตา — โกงจากเครื่องตัวเองไม่ได้ |
| เผ่า | 6 แบบ: มนุษย์ · เอลฟ์ · คนแคระ · ฮาล์ฟลิ่ง · ออร์ค · ทีฟลิ่ง |
| อาชีพ | 9 แบบ: นักรบ · นักเวท · โจร · นักบวช · พรานป่า · กวีพเนจร · นักตกปลา · ช่างตีเหล็ก · พ่อครัว |
| ค่าพลัง | ทอยลูกเต๋า 6 หน้าสี่ลูก ทิ้งลูกต่ำสุด ทำทีละค่า ครบ 6 ค่า · HP = 10 + โบนัสความอึด (อย่างน้อย 4) |
| สุ่มใหม่ | 4 ปุ่ม: **สุ่มเฉพาะอันนี้** ใต้เผ่า · **สุ่มเฉพาะอันนี้** ใต้อาชีพ · ปุ่มกลม = สุ่มเฉพาะค่าพลัง · **n/6 สุ่มใหม่** = สุ่มทั้งตัว |
| สิทธิ์ | ทุกปุ่มใช้สิทธิ์จาก**กองเดียวกัน 6 ครั้ง** กดครั้งละ 1 ไม่ว่าปุ่มไหน · หมดแล้วปุ่มเป็นสีเทา |
| ไม่เสียสิทธิ์ฟรี | สุ่มเผ่าหรืออาชีพใหม่ ไม่มีทางได้อันเดิมซ้ำ |
| กดพร้อมแล้ว | สุ่มไม่ได้ ต้องกด "ไม่พร้อม" ก่อน |
| ลุกแล้วกลับมา | บัญชีเดิมกลับมาได้**ตัวเดิม** (เผ่า อาชีพ ค่าพลัง สิทธิ์ที่เหลือ) — ลุกแล้วนั่งใหม่เพื่อสุ่มฟรีไม่ได้ |

### ออกเดินทาง

- **ทุกคนที่นั่งอยู่กดพร้อม → เริ่มเอง** ไม่ต้องมีใครกดเริ่ม ทุกจอเข้าหน้าเกมภายในราว 1.5 วินาที
- ไม่ต้องรอคนครบตามจำนวนที่ตั้ง (ตั้ง 4 มา 2 แล้วทั้งคู่พร้อม ก็ออกเดินทางเลย)
- Claude ได้ข้อความเริ่มพร้อมยุค เหตุการณ์ ระดับ
- มาทีหลังตอนเริ่มไปแล้วก็เข้าได้ (ถ้ายังไม่เต็ม) ได้ตัวที่สุ่มแล้วเข้าเกมเลย
- ห้องเต็ม → "ห้องเต็มแล้ว"

### เจ้าของห้อง

- เจ้าของ (มีมงกุฎ) มีปุ่ม **ตั้งค่าห้อง** ที่กองไฟ → เปิดหน้าเดียวกับสร้างห้อง เปลี่ยนจำนวนคน ยุค เหตุการณ์ได้ระหว่างรอ แล้วกด "บันทึก →"
- ลดจำนวนคนต่ำกว่าคนที่นั่งอยู่แล้วไม่ได้ (ไล่ใครออกไม่ได้)
- **แก้รอบนี้:** เจ้าของลุกไป → มงกุฎไปอยู่กับคนที่มาถึงก่อนสุดที่ยังนั่งอยู่ เจ้าของตัวจริงกลับมาก็ได้คืน
  (เดิมเจ้าของลุกแล้วไม่มีใครตั้งค่าห้องได้เลย) · ถ้าเจ้าของอยู่คนเดียวแล้วลุก คนแรกที่มานั่งถือมงกุฎแทนไปก่อน
- คนที่ถือมงกุฎแทน ตั้งค่าห้องได้ แต่รายการห้องของเขาไม่ขึ้นว่าเป็น "เจ้าของ" — ห้องยังเป็นของคนที่เปิด

### ป้ายชื่อที่กองไฟ (แก้รอบนี้)

- ป้ายไม่ทับกันแล้ว ป้ายที่จะทับจะเลื่อนลงใต้ป้ายอื่น ถ้าเลื่อนไม่พอก็จางลง
- ชื่อยาวตัดด้วย "…" ที่ราว 10 ตัวอักษรไทย เช่น "ศรีสุริโยทัยมห…" ไม่ตัดสระหรือวรรณยุกต์ออกจากตัวอักษร
- **ป้ายของเราเด่นเสมอ** ไม่จาง ไม่ถูกบัง วาดทับทุกป้าย
- ป้ายไม่หลุดขอบจอบนมือถือแล้ว

## 6. แต่งตัวละคร

เปิดได้จากป้ายรอบตัวในหน้าตัวละคร D&D และปุ่ม "แก้ไขรูปลักษณ์" ที่กองไฟ

| แท็บ | มีอะไรให้เลือก | กล้อง |
| --- | --- | --- |
| **ผม** | ทรง 5: สั้น ยาว มัด โกน ฮู้ด · สีผม · หมวก 8: ไม่ใส่ หมวกเหล็ก ฮู้ด มงกุฎ ผ้าโพก ปีกกว้าง หมวกแหลม รัดเกล้า | ซูมที่หัว |
| **หน้าตา** | รูปหน้า 6: กลม รูปไข่ เหลี่ยม ยาว หัวใจ คางแหลม · รายละเอียด 6: เรียบ แผลเป็น เครา หนวด รอยสัก หน้ากาก | ซูมที่หัว |
| **ลำตัว** | รูปร่าง 8: มาตรฐาน ผอม ไหล่กว้าง ล่ำ สูง ตัวเล็ก ท้วม ปราดเปรียว · สีผิว | ทั้งตัว |
| **เสื้อผ้า** | ชุด 8: ทูนิก ชุดคลุมยาว ชุดเกราะ เสื้อคลุม ผ้าคลุมไหล่ ชุดยาว ชุดหนัง ผ้าขาด · สีเสื้อ · สีผ้าคลุม (โผล่เมื่อเลือกเสื้อคลุมหรือผ้าคลุมไหล่) | ทั้งตัว |

- ทุกตัวเลือกเป็นช่องรูปวาดเส้นเล็ก ๆ + ชื่อไทย
- **สี:** จุดสีสำเร็จรูป 8 สี + ปุ่ม "+" เลือกสีเอง = สี่เหลี่ยมเลือกสี + แถบเฉดสี + ช่องพิมพ์รหัสสี
- ตัวอย่างหมุนเองช้า ๆ
- เผ่าที่สุ่มได้กับอาวุธตามอาชีพขึ้นบนตัวหมากเอง
- ปุ่มล่าง: **กลับ** = ทิ้งที่แก้ · **✓** = เก็บ · **ต่อไป →** = แท็บถัดไป (แท็บสุดท้ายเป็น "เสร็จ")

**Realtime** — แต่งตัวจากกองไฟจะมีป้าย "Realtime — ทุกคนที่กองไฟเห็นทันที"
ทุกการเปลี่ยนส่งขึ้นห้องทุก ~0.4 วินาที ลากเลือกสีอยู่คนอื่นก็เห็นสีเปลี่ยนตาม
กด "กลับ" = ส่งหน้าตาเดิมกลับไปให้ทุกคน · นอกห้อง หน้าตาจำไว้ในเครื่อง แล้วใช้ตอนสร้างหรือเข้าห้อง

## 7. หน้าเกม D&D

แทบเหมือนเดิม: กระดาน · เรื่องเล่า · HP −1/+1 · ปุ่มลูกเต๋า · ช่อง "ทำอะไร?"

- ลูกเต๋าทอยที่เซิร์ฟเวอร์ แล้ว**กลิ้งบนกระดานของทุกคน** — จึงไม่ต้องมีถาดลูกเต๋าแยกแล้ว
- ชื่อเผ่าและอาชีพเป็นภาษาไทย
- Claude (ผู้เล่าเรื่อง) เห็นยุค เหตุการณ์ ระดับ และเผ่า/อาชีพของทุกคนเป็นภาษาไทย
  ได้รับคำสั่งให้เปิดเรื่องตามที่เลือก และให้ใช้อาชีพธรรมดา ๆ อย่างนักตกปลาหรือพ่อครัวในเรื่องด้วย
  *(ยังไม่ได้ลองเล่นกับ Claude จริง ว่าเล่าออกมาดีแค่ไหน)*

- ภูมิประเทศเลือกแยกจากแผนที่: แผนที่บอกสีกับของบนพื้น ภูมิประเทศบอกความสูงต่ำ
- แผนที่สองชื่อเปลี่ยน เพราะชนกับชื่อภูมิประเทศ: ป่าเนินเขา → **ป่าไม้** · ที่ราบหิมะ → **ทุ่งหิมะ**
- ปิดสิ่งก่อสร้าง = ไม่มีตึก กำแพง หอ เหลือแต่ของธรรมชาติ
- สิ่งก่อสร้าง "มาก" แล้วตัวหมากก็ไม่เกิดในตึก · จิ้มจุดลงสนามโดนสิ่งกีดขวาง จะบอกให้เลือกที่โล่ง
- เล่นกับเพื่อน: ห้องส่งภูมิประเทศกับสิ่งก่อสร้างไปด้วย ทุกเครื่องได้สนามเดียวกัน

**โหมดผู้ชม** — "เราเป็นคนจัดแล้วดูอย่างเดียวให้บอทมันตีกัน"

- ทุกฝ่ายเป็นบอท ได้ถึง 8 ฝ่าย · ตั้งจำนวนฝ่ายกับงบได้ในหน้าตั้งค่า ไม่ต้องผ่านหน้าจัดทัพ
- ปุ่ม: หยุด / เล่นต่อ · ×1 ×2 ×4 · ทีละจังหวะ · **ดูอีกรอบ ↻** (สนามใหม่ แมตช์ใหม่)
- เร่ง ×4 แล้วตัวหมากก็เดินเร็วขึ้นด้วย ไม่ใช่แค่บอทคิดเร็ว
- เล่นในเครื่องเดียว ไม่มีห้อง

บอทแก้เพิ่ม: เปิดฟรีฟายไว้ก็ยังเล็งศัตรูก่อน ยิงพวกเดียวกันเฉพาะตอนไม่เหลือศัตรูแล้ว

## 10. แอพ Android = กรอบของหน้าเว็บ

แอพเหลือหน้าของตัวเองแค่ 4 หน้า ที่เหลือคือหน้าเว็บเดียวกับบนคอม

| หน้าของแอพเอง | ทำไมยังต้องมี |
| --- | --- |
| "กำลังเข้าสู่ระบบ…" | ขึ้นระหว่างเช็กบัญชีและโหลดหน้าเว็บ |
| เข้าสู่ระบบ | ปุ่ม Google ของหน้าเว็บใช้ในแอพไม่ได้ (Google บล็อก) จึงใช้ของเครื่องแทน แต่หน้าตาเหมือนเว็บ · มีผู้เล่นรับเชิญกับรหัสจับคู่เหมือนกัน |
| ไม่มีเน็ต | "ไม่มีอินเทอร์เน็ต — เล่นโต๊ะรบกับบอทได้" + ปุ่ม "เล่นโต๊ะรบกับบอท ›" + "ลองใหม่" |
| โต๊ะรบออฟไลน์ | โต๊ะรบฝังอยู่ในแอพ เล่นกับบอทได้แม้ไม่มีเน็ต |

- เข้าสู่ระบบแล้ว แอพเปิดหน้าเว็บและส่งตัวตนให้ ไม่ต้องล็อกอินซ้ำ · ที่กองไฟขึ้นไอคอนมือถือ
- ปุ่มย้อนกลับของเครื่อง: ถอยทีละหน้า หรือปิดหน้าต่างที่เปิดอยู่ · อยู่หน้าบนสุดแล้วกดอีกทีปิดแอพ
- กด "ออกจากระบบ" ในหน้าเว็บ → กลับหน้าเข้าสู่ระบบของแอพ
- ล็อกอินไม่สำเร็จ (เช่นเน็ตหลุด) มีลิงก์ "เล่นโต๊ะรบกับบอทแบบออฟไลน์ ›"
- **เซิร์ฟเวอร์ยังเป็นรุ่นเก่า** → แอพขึ้น "เซิร์ฟเวอร์ยังไม่รองรับแอพรุ่นนี้ — เล่นโต๊ะรบกับบอทได้" (เหตุผลของลำดับ merge ในข้อ 15)
- รุ่นแอพ 2.0.0
- โปรแกรม Windows เปิดหน้าเว็บเดียวกันอยู่แล้ว จึงได้หน้าใหม่ทันทีที่เซิร์ฟเวอร์อัปเดต

ข้อดีที่ได้: ต่อไปแก้หน้าจอครั้งเดียว ขึ้นทุกเครื่องพร้อมกัน ส่วนใหญ่ไม่ต้องออกแอพรุ่นใหม่ด้วย

## 11. เซิร์ฟเวอร์ — ของที่มองไม่เห็นแต่แก้แล้ว

- **หลายคนกดพร้อมกันตอนเซิร์ฟเวอร์ยุ่ง** เดิมบางคำสั่งหลุด (ขึ้นข้อผิดพลาด) ตอนนี้รอคิวได้นานขึ้น สูงสุดราว 6 วินาที
  ทดสอบตอนเครื่องยุ่ง 648 คำสั่ง ไม่หลุดสักคำสั่ง (ก่อนแก้ หลุด 40 จาก 360)
- **เปิดหน้าซ้ำเร็วขึ้น** — หน้าเว็บไม่เปลี่ยน เบราว์เซอร์ใช้ของที่มีอยู่ในเครื่องได้ ไม่ต้องโหลดใหม่ทั้งหน้า หน้าเปลี่ยนเมื่อไหร่ก็ได้ของใหม่ทันที
- ห้อง D&D กับโต๊ะรบใช้รหัสชุดเดียวกัน เดิมเอารหัสโต๊ะรบไปเปิดฝั่ง D&D ได้ ตอนนี้ตอบว่า "ไม่พบห้อง"
- ข้อมูลบัญชีของผู้เล่นคนอื่นไม่ถูกส่งออกไปกับข้อมูลห้องแล้ว
- ทุกคำสั่งของผู้เล่นเช็กว่าเป็นตัวละครของบัญชีนั้นจริง ไม่ใช่ก็ตอบ "ไม่ใช่ตัวละครของคุณ"
- แอพรุ่นเก่ายังสร้างและเข้าห้องแบบเดิมได้ ห้องที่เปิดไว้ก่อนอัปเดตก็ยังเล่นต่อได้
  *(ตรวจด้วยสคริปต์ที่ส่งคำสั่งแบบเดียวกับแอพเก่า ไม่ได้ลองกับมือถือที่ลงแอพเก่าจริง)*

| ชุด | ผล |

## 14. ข้อจำกัดที่รู้อยู่

- ทดสอบบน**มือถือจำลองในเบราว์เซอร์** ยังไม่ได้ลองบนมือถือจริง
- โค้ดแอพ Android คอมไพล์ในเครื่องที่ผมใช้ไม่ได้ — ระบบของ GitHub ใน PR #8 เป็นตัวคอมไพล์ **ดูให้ขึ้นเขียวก่อนกด merge** ยังไม่มีใครลองติดตั้ง APK ใหม่จริง
- บัญชีเดียวกันสองเครื่องแต่งตัวในจังหวะเดียวกันพอดี: อันที่ถึงเซิร์ฟเวอร์ทีหลังชนะ
- คนที่ยังใช้แอพรุ่นเก่าเข้าห้องแบบใหม่ได้ แต่ไม่เห็นกองไฟ ได้ตัวสุ่มและนับว่า "พร้อม" ทันที
- ห้องที่เปิดก่อนอัปเดตเป็นห้องแบบเก่า ไม่มีกองไฟ เข้าเกมเลย
- โหมดผู้ชมดูในเครื่องตัวเองเท่านั้น เปิดห้องให้คนอื่นมาดูด้วยไม่ได้
- ในหน้าเว็บยังไม่มีปุ่มปิดห้องทิ้ง (รอบก่อนก็ไม่มี) มีแค่ "ออกจากห้อง"
