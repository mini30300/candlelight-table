# สรุปแผนแอปใหม่ โต๊ะเทียน บน Godot

เขียนให้มินิอ่านหรือฟังได้ง่าย ไม่มีศัพท์โปรแกรม ถ้าอยากรู้รายละเอียดเชิงช่าง ให้เปิดไฟล์ ARCHITECTURE.md กับ PLAN.md

## แอปใหม่คืออะไร

แอปใหม่คือโต๊ะเทียนตัวเดิม แต่สร้างใหม่ด้วยเครื่องมือทำเกมชื่อ Godot
เป็นแอปจริงบนมือถือ Android และบน Windows ไม่ใช่หน้าเว็บที่ห่อไว้ในแอปอีกต่อไป
ตัวหมากจะเป็นโมเดลสามมิติจริงที่การ์ดจอวาด เดินได้นุ่มนวล ยิงได้ ฟันได้ เหมือนของจริงมากขึ้น
โต๊ะรบมาก่อน พอโต๊ะรบเล่นออนไลน์ได้แล้ว ค่อยทำโต๊ะ D&D ต่อ

เราเลือกแบบที่ชื่อว่า มือถืออ่อนและความตรงกันมาก่อน
หมายความว่าออกแบบให้เครื่องถูกเล่นได้ลื่นตั้งแต่ต้น และทุกเครื่องในห้องเดียวกันคิดผลได้ตรงกันเป๊ะ
จากนั้นเอาจุดเด่นของอีกสองแบบมาเสริม คือ ส่งของให้มินิดูบนมือถือตั้งแต่สัปดาห์แรก และวางโครงให้โต๊ะ D&D ต่อยอดได้โดยไม่ต้องรื้อ

## สิ่งที่เราเก็บไว้

เซิร์ฟเวอร์เดิมใช้ต่อทั้งหมด ห้องเดิม รหัสห้องเดิม วิธีเข้าห้องเดิม
Claude ยังนั่งเล่นโต๊ะรบได้เหมือนเดิม และยังเป็นผู้เล่าเรื่องโต๊ะ D&D ได้เหมือนเดิม
ตัวหมากทั้งสามร้อยกว่าตัว ย้ายมาจากหน้าเก่าโดยอัตโนมัติ ไม่ต้องปั้นใหม่
กติกา แต้ม กองทัพทั้งสิบห้า และลูกเต๋า เหมือนเดิมทุกข้อ ย้ายมาจากตารางของหน้าเก่าโดยตรง
ท่าเดินและท่าโจมตีที่มินิเคยชอบ ถูกอัดเก็บไว้จากตัวเดินเดิม แล้วเอามาใช้กับโมเดลใหม่
แอปเก่ายังใช้ได้และยังออกรุ่นใหม่ได้ตามปกติ จนกว่าแอปใหม่จะตามทัน ติดตั้งคู่กันได้ ไม่ทับกัน

มีข้อเดียวที่เปลี่ยน คือห้องของแอปใหม่เป็นกติการุ่นสิบ ห้องของแอปเก่าเป็นรุ่นเก้า
แอปเก่ากับแอปใหม่จะไม่เข้าห้องเดียวกัน เพราะการคำนวณข้างในต่างกันเล็กน้อย
เซิร์ฟเวอร์จะบอกเองว่าห้องนี้ใช้แอปไหน ไม่มีใครเข้าผิดห้องแล้วเห็นภาพไม่ตรงกัน

## ขั้นตอน พูดให้ง่าย

ขั้นที่ศูนย์ ประมาณสองสัปดาห์แรก
วางโครงแอป ทำให้สร้างไฟล์ติดตั้งได้เองทุกครั้งที่รวมงาน
มินิจะได้ลองแอปที่มีสนามจริง ตัวหมากจริงสี่ร้อยตัวย้อมสีทีม หมุนดู ซูมดูได้ และมีหน้าตรวจเครื่อง

ขั้นที่หนึ่ง ประมาณสามสัปดาห์
ย้ายกติกาทั้งหมดมาเป็นแกนใหม่ที่คิดด้วยเลขจำนวนเต็ม ทุกเครื่องจึงคิดได้ตรงกัน
ตรวจกับหน้าเก่าอย่างละเอียด ว่าเล่นแล้วได้ผลเหมือนเดิม
ระหว่างนี้มีของให้ดูทุกสัปดาห์ คือ สนามแต่ละแบบ ตัวหมากเดิน หน้าเลือกกองทัพ

ขั้นที่สอง ประมาณสามถึงสี่สัปดาห์
เล่นกับบอทได้ครบทั้งเกมบนมือถือ โดยไม่ต้องต่อเน็ต
ครบทุกหน้า ครบไทยและอังกฤษ ลื่นบนระดับกราฟิกต่ำสุด

ขั้นที่สาม ประมาณสองสัปดาห์
เล่นออนไลน์ผ่านเซิร์ฟเวอร์เดิม ชวนเพื่อนและ Claude เข้าห้องได้
ออกรุ่นคู่กับแอปเก่าในหน้าเดิม

ขั้นที่สี่ ประมาณสามถึงสี่สัปดาห์
โต๊ะ D&D ที่คนเป็นผู้เล่าเรื่องได้เต็มรูปแบบ มีแผงควบคุมของผู้เล่าเรื่องในแอป
แผนที่สุ่มสร้างเอง ทุกเครื่องเห็นแผนที่เดียวกัน Claude ก็อ่านแผนที่ได้

ขั้นที่ห้า ประมาณห้าถึงหกสัปดาห์
โหมดเอาชีวิตรอดแบบโหด หิว กระหาย เหนื่อย กลัว บาดเจ็บ ตายแล้วตายเลย
มอนสเตอร์หกสิบกว่าแบบจากตัวหมากที่มีอยู่ แล้วค่อยเพิ่มใหม่ ก่อนลงมือจะคุยออกแบบกับมินิและจีพีทีก่อนหนึ่งสัปดาห์

ขั้นที่หก ประมาณหนึ่งเดือน
เก็บงานที่เหลือ เล่นโหมดเอาชีวิตรอดร่วมกันหลายคน ท่าเดินละเอียดขึ้นอีก
แล้วให้แอปใหม่อัปเดตทับแอปเก่าบนมือถือ เหลือแอปเดียว

รวมแล้วโต๊ะรบเล่นออนไลน์ได้ราวสองเดือนครึ่ง โต๊ะ D&D กับโหมดเอาชีวิตรอดอีกราวสามเดือน
ถ้ามีคนทำสามถึงห้าคนพร้อมกัน ถ้าทำคนเดียวจะนานกว่านี้ราวสองเท่า

## มินิจะเห็นอะไรก่อน และเมื่อไหร่

สัปดาห์ที่หนึ่งถึงสอง จะมีไฟล์ติดตั้งในหน้า Releases ชื่อ build ตามเลขรอบ เหมือนทุกวันนี้
มีทั้งไฟล์มือถือและไฟล์ Windows ติดตั้งแล้วจะเห็นสนาม ตัวหมากสี่ร้อยตัว และหน้าตรวจเครื่อง
จากนั้นทุกสัปดาห์จะมีรุ่นใหม่ให้ลองดูว่าสวยขึ้นตรงไหน
ราวสัปดาห์ที่หกถึงเจ็ด จะเล่นกับบอทได้ทั้งเกม
ราวสัปดาห์ที่เก้าถึงสิบ จะเล่นออนไลน์กับเพื่อนและ Claude ได้

## มินิต้องทำอะไร

หนึ่ง กดรวมงานตามลำดับที่เราเขียนไว้ในแต่ละงาน ถ้ามีงานฝั่งเซิร์ฟเวอร์ ให้รวมฝั่งเซิร์ฟเวอร์ก่อนเสมอ
งานแรกที่รอรวมคือ PR 27 ของโต๊ะเทียน ซึ่งเป็นโครงแอปใหม่

สอง ติดตั้งไฟล์ทดลองบนมือถือและบนคอม แล้วส่งภาพหน้าจอหน้าตรวจเครื่องมาให้ดู
ลองพิมพ์ชื่อภาษาไทยในช่องชื่อ แล้วบอกว่าพิมพ์ได้ไหม
คอมเครื่องเก่าอาจเปิดไม่ขึ้น ถ้าเปิดไม่ขึ้นให้บอก เรามีทางสำรองเตรียมไว้

สาม เมื่อถึงขั้นเล่นกับบอทได้ ให้ลองเล่นหนึ่งเกมบนมือถือที่ระดับกราฟิกต่ำสุด แล้วบอกว่าลื่นไหม ร้อนไหม ท่าเดินดูเป็นธรรมชาติไหม

สี่ เรื่องความลับ ไม่ต้องส่งอะไรมาในแชทเลย
กุญแจเซ็นแอปและรหัสต่างๆ อยู่ในหน้า Settings ของ GitHub Actions อยู่แล้ว แอปใหม่ใช้ชุดเดิม ไม่ต้องเพิ่มใหม่
ถ้ามีงานไหนต้องการความลับเพิ่ม เราจะหยุดแล้วบอกชื่อช่องที่ต้องใส่ และใส่ที่หน้านั้นเท่านั้น

ห้า เรื่องชื่อหน่วย ยังใช้ชื่อแบบของเราเองทั้งหมด ไม่ใช้ชื่อจากค่ายเกมอื่น เหมือนกติกาเดิมของรีโป

## เพิ่มเติม 7 ต.ค. จากที่มินิบอกหลังลองแอปบนมือถือ

แอปทดลองเปิดบนมือถือของมินิได้แล้ว การ์ดจอชื่อ Mali G52 จอ 2400 คูณ 1080 ได้ 21 เฟรมต่อวินาทีตอนเปิดเงาเต็มความละเอียด
ดังนั้นมือถือจะใช้ระดับกราฟิกต่ำเป็นค่าเริ่มต้น คือวาดที่ความละเอียดลดลงและไม่มีเงา แล้วค่อยให้เลือกสูงขึ้นเอง

สิ่งที่มินิขอเพิ่ม และเราปรับแผนแล้ว
หนึ่ง สีทีมไม่ย้อมลงบนตัวโมเดลอีกต่อไป ใช้วงแหวนสีบนพื้นใต้ตัวแต่ละตัวแทน ตัวหมากจึงเก็บสีของตัวเองไว้ได้
สอง ตัวเพ้นท์โมเดล ให้เลือกสีทีละส่วนของตัวหมากได้ และเพื่อนในห้องเห็นสีที่เราเพ้นท์ด้วย
สาม โหมดสะสม คือตกแต่งโมเดล มีกล่องโมเดลวางบนชั้นหรือโต๊ะให้กดเปิดดู และโหมดแคมเปญที่เล่นแล้วได้เหรียญในเกมไปสุ่มโมเดล
ข้อสามเป็นขั้นที่เจ็ดในแผน จะคุยออกแบบกับมินิก่อนลงมือ ใช้เหรียญในเกมเท่านั้น ไม่มีเงินจริง และบอกโอกาสสุ่มบนหน้าจอ
ตัวหมากทั้งหมดยังเล่นโต๊ะรบได้ตั้งแต่ต้น การสะสมมีผลแค่หน้าตา เพื่อให้เกมยุติธรรม
