# 20 ก.ย. 69 (รอบ 2) — แอพมือถือหน้าตาเหมือนหน้าคอมแล้ว

รีโป: `candlelight-table` (`app/src/main/java/dev/mini/candlelight/`)
ต้นทาง: มินิถามว่า "ทำแค่ของคอมหรอครับมือถือไม่ได้ทำหรอ" → "ครับเอาเหมือนกันเลยครับ"

---

## หน้าแรก = หน้าเลือกโหมด เหมือนบนคอมเป๊ะ

| การ์ด | ภาพ | ยังไม่ล็อกอิน | ล็อกอินแล้ว |
| --- | --- | --- | --- |
| **D&D** | คนนั่งรอบโต๊ะ | ปุ่ม Google + เส้นคั่น "หรือ" + ปุ่มเกสต์ | รายการ 3 แถว (สร้างตัวละคร / Claude เล่าเรื่อง / ทอยเต๋า) + ปุ่มใหญ่ |
| **เทเบิลท็อป** | หุ่นถือดาบบนกระดาน | รายการเครื่องมือ 4 อย่าง + ปุ่มเข้า | เหมือนกัน |
| **เชื่อมเครื่องอื่น** | มือถือ ↔ คอม | ช่องใส่รหัสจับคู่ + ปุ่ม "เชื่อม" | ปุ่มขอรหัส |

ภาพประกอบทั้ง 9 ชิ้นเป็นชุดเดียวกับหน้าเว็บ แปลงจาก SVG มาเป็น Canvas ของ Compose
(`Illustrations.kt`) ไม่ได้ใช้ไฟล์รูปเลย เส้นหนาเท่ากันทุกขนาดเหมือน `non-scaling-stroke`

ขนาดตัวอักษร/ภาพ/ระยะห่าง ลอกจาก CSS ของหน้าเว็บที่ breakpoint มือถือ (`max-width:699px`) ตรง ๆ —
ชื่อการ์ด 20sp, เนื้อ 14sp/21, บรรทัดล่าง 12sp, ไอคอนเครื่องมือ 36×24dp, แถบภาพสูง 136dp พร้อมแสงเทียนจาง ๆ ข้างใต้

## เทเบิลท็อปเปิดได้ตั้งแต่ยังไม่ล็อกอิน

หน้าโต๊ะ 4 หน้าอยู่ในแอพอยู่แล้ว ไม่ต้องต่อเน็ต เลยไม่ควรต้องล็อกอินก่อน — ย้ายลำดับใน `App()`
ให้เช็ค `play == "tabletop"` เป็นอันแรก ตรงกับที่หน้าเว็บเขียนว่า "ไม่ต้องเข้าสู่ระบบ"

## ใส่รหัสจับคู่ในมือถือได้แล้ว

เดิมมือถือ**ขอ**รหัสได้อย่างเดียว ตอนนี้**ใส่**รหัสได้ด้วย (`Api.pairClaim`) — ลงแอพในเครื่องที่สอง
แล้วเอารหัสจากเครื่องแรกมาใส่ ก็เข้าบัญชีเดียวกันโดยไม่ต้องล็อกอิน Google ซ้ำ

## ที่ยังไม่ได้แตะ

หน้าล็อบบี้กับหน้าเล่นยังเป็นของเดิม เปลี่ยนแค่แถบหัวให้เป็นชุดเดียวกัน

## ตรวจยังไงทั้งที่ build Kotlin ในเครื่องนี้ไม่ได้

1. `kt2canvas.py` แปลงตัวภาพจาก Kotlin เป็น canvas JS แล้ววาดออกมาดู — จับพิกัดพิมพ์ผิดได้โดยไม่ต้องมี APK
2. จำลองหน้าจอทั้ง 3 หน้าที่ความกว้าง 412dp ด้วยภาพชุดเดียวกัน เทียบกับหน้าเว็บทีละตัวเลข
3. ตรวจวงเล็บ/ปีกกา/escape ทุกไฟล์ให้ครบคู่ (เจอ 1 ที่ที่ปีกกาหาย แก้แล้ว)
4. ที่เหลือให้ CI ของ GitHub คอมไพล์จริง — job `check`

## ที่มินิต้องทำ

1. **merge PR** ที่ `candlelight-table` → รอ ~1–2 ชม. ให้ Actions build แล้วโหลด .apk จากแท็บ Releases
2. ติดตั้งทับแอพเดิมได้เลย **อย่าถอนของเก่าก่อน** ไม่งั้นล็อกอินหาย (เวอร์ชัน 1.3.0)
3. ยังค้าง: 🔴 ตั้ง `DM_KEY` · 🔴 เพิกถอน GitHub PAT ตัวเก่า
