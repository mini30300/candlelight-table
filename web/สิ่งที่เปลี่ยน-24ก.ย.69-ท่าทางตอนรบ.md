## 1. ตัวหมากขยับตามลูกเต๋า

ลูกเต๋าในถาดกลิ้งจังหวะไหน ตัวหมากก็เล่นท่าของจังหวะนั้น ทุกเครื่องในห้องเห็นเหมือนกัน
เป็นภาพอย่างเดียว กติกากับผลลูกเต๋าไม่เปลี่ยน

**ตอนทอยเข้าเป้า** คนโจมตีหันไปหาเป้าแล้วลงมือ นัดที่เข้าวิ่งไปโดนตัว นัดที่พลาดเฉียดเลยไป

| หน่วย | ท่า |
| --- | --- |
| เกราะหนัก ทหารราบ จู่โจม | ยกปืนประทับบ่า ยิงทีละนัด ปืนสะท้อน ไฟแลบที่ปากกระบอก มีควัน กระสุนวิ่งเป็นเส้น |
| ปืนกลหนัก | ยิงจากสะเอว รัวทีละ 5 นัด |
| พลซุ่มยิง | เล็งกล้องนิ่ง ๆ ก่อน แล้วยิงนัดเดียว กระสุนเป็นเส้นสีฟ้า |
| หุ่นรบ | ยกปืนใหญ่ ยิงทีละนัด ไฟแลบกับควันใหญ่ |
| นักธนู | ยกคันธนู ง้างสายถึงแก้ม คันธนูโค้งตาม ปล่อยลูกธนูโค้งไปปักเป้า |
| ทหารหอกซัด | เงื้อเหนือศีรษะ ขว้างทีละเล่ม (สูงสุด 2 เล่ม) หอกลอยโค้งไปปัก |
| โฮพไลต์ สปาร์ตัน ทหารม้า (ประชิด) | ง้างหอกเหนือไหล่ แทงพร้อมโถมตัว สูงสุด 3 ครั้ง |
| หน่วยปืน (ประชิด) | กระแทกด้วยปืนสองมือ |

**โล่** — ตัวที่ถือโล่ (โฮพไลต์ สปาร์ตัน ทหารหอกซัด ทหารม้า) ยกโล่ขึ้นบังอกถึงใต้ตาตั้งแต่ศัตรูเริ่มโจมตี
หันหน้าโล่ไปทางคนโจมตี เอนตัวเข้าหาโล่นิดหนึ่ง โดนแล้วโล่สะท้าน ยกค้างไว้จนลูกเต๋าของการโจมตีนั้นหยุดครบ
ถ้าโดนหลายตัวรุมติดกัน ยกค้างไว้ไม่ลดลง และหันไปหาคนโจมตีคนใหม่

**หน่วยแพทย์** — ลดปืนลงข้างตัว ยื่นมือไปหาเพื่อน รักษาสำเร็จมีวงแสงสีเขียวลอยขึ้น

**ตอนลูกสุดท้ายหยุด**

- เซฟได้ = ประกายสีทองกระเด็น
- เจาะเกราะไม่เข้า = ประกายสีเทา
- โดนจริง = ประกายสีแดง ตัวสะดุ้ง (ถ้ายกโล่อยู่ โล่สะท้านแรงแทน)
- แผลหมด = ล้มหงายไปทางตรงข้ามกับคนโจมตี กระแทกพื้นมีฝุ่น แล้วค่อย ๆ จางหาย (ตัวที่ยกโล่อยู่ล้มทั้งท่ายกโล่)

## 2. ที่แก้ระหว่างทำ

- **โล่เป็นหมวก** — ตอนแรกยกโล่สูงแล้วโล่นอนราบเหนือหัวเหมือนหมวก แก้ให้โล่หันหน้าไปทางศัตรูเสมอไม่ว่ายกแขนท่าไหน
- **ท่าทางรีบเกินไปตอนเปิดออโต้หรือตาบอท** — เดิมลูกเต๋าสามจังหวะของการโจมตีเดียวกันถูกนับว่า "ค้างคิว" เลยเร่ง 2.6 เท่า
  ตอนนี้เร่งเฉพาะตอนค้างหลายการโจมตีจริง ๆ (เช่นพับแอปไว้แล้วกลับมา) การโจมตีปกติเล่นความเร็วจริง
- **ยกโล่ค้างไม่กินเครื่อง** — ตอนรอคนกดทอย โล่ที่ยกนิ่งอยู่ไม่ทำให้จอวาดใหม่ทุกเฟรม

## 3. ถ้าลองเอง

TABLETOP → สร้างโต๊ะ → เลือกกองกรีกฝั่งหนึ่ง กองทหารอีกฝั่ง → ลงสนาม → แตะตัวเรา แตะศัตรู → กด 🎲 ทอย
ลองให้นักธนูยิงโฮพไลต์ ดูโล่ยกขึ้นรับ แล้วลองให้โฮพไลต์เดินเข้าประชิดแทงทหารราบ
เปิด **ออโต้** แล้วดูบอทเล่นก็เห็นทุกท่าต่อกันเอง

## 4. ทดสอบแล้ว

- ดูทีละเฟรมทุกหน่วย ทั้งคนโจมตี (มองจากข้าง) และเป้า (มองจากหน้า): ปืนสามแบบ ปืนกลหนัก ซุ่มยิง หุ่นรบ ธนู หอกซัด หอกยาว ทหารม้า กระแทกด้วยปืน หมอ
- โล่: ยกขึ้นเต็มภายใน 0.6 วินาที ค้างไว้ตลอดสองการโจมตีติดกัน หันตามคนยิงคนที่สอง แล้วลดลงเมื่อจบ · ตอนรอคนกดทอยโล่ยกค้างและไม่วาดจอใหม่ (10 ข้อผ่าน)
- ชุดทดสอบโต๊ะรบเดิมทั้งหมด (ลูกเต๋า บอท โหมดผู้ชม หลายทีม นาฬิกา มือถือ ภูมิประเทศ ห้องออนไลน์ ฯลฯ) · ท่าเดินของโมเดล · ลูกเต๋า 2,400 ลูกตกตรงเลข
