# 20 ก.ย. 69 (รอบ 8) — ห้อง · เล่นข้ามเครื่อง · บอทแทนคนหาย · Claude ลงเล่นเอง

## 0. หน้าเลือกเครื่องมือ — เอาออกแล้ว

กด **เทเบิลท็อป** แล้วเข้า **โต๊ะรบ** เลย ทั้งหน้าเว็บและในแอพ

อีก 3 หน้า (แผนที่โลก ถาดลูกเต๋า โครงกระดูก) **ไม่ได้ลบ** ยังอยู่ครบ เสิร์ฟที่ `/tabletop/<ชื่อ>` เหมือนเดิม แค่ไม่มีเมนูหน้าบ้านแล้ว — อยากเอากลับมาเมื่อไหร่ก็ได้

## 1-2. ห้อง กับ เล่นข้ามเครื่อง

กด **"เปิดห้องใหม่"** → ได้รหัส 5 ตัว → บอกเพื่อน → เพื่อนพิมพ์รหัสเข้ามา → ชื่อเด้งขึ้นในล็อบบี้ → แต่ละคนเลือกทีมเอง → เจ้าของกดเริ่ม

**ที่นั่งว่างมีบอทนั่งแทน** — ตั้ง 2v2 แล้วมากันแค่ 2 คน ก็ยังได้ 4 กองทัพ ไม่ใช่ 2

### วิธีซิงก์ — บางกว่าที่คิด

เกือบทั้งหมดของแมตช์**คำนวณเอาเองได้** ถ้า seed · แมพ · ขนาดโต๊ะ · กองทัพ · จุดลงสนาม เหมือนกัน `deploy()` จะสร้างกองทัพ**เหมือนกันเป๊ะทุกเครื่อง**

ห้องเลยเก็บแค่ **ค่าสนาม + กองของแต่ละคน + จุดลงสนาม** แล้วตามด้วย **ลำดับสิ่งที่คนทำ**
ลูกเต๋าเดินทางไปกับการกระทำที่ทอยมัน ทุกจอจึงเห็นเลขเดียวกัน ไม่ใช่ต่างคนต่างทอย

ถามเซิร์ฟเวอร์ทุก **1.5 วินาที** — เกมผลัดตากันเหลือเฟือ (กระดาน D&D ในแอพใช้ 2 วิมาตลอด)

### สามบัคที่เสียเวลาหาที่สุด

**บอทเดินคนละทางบนแต่ละจอ** — เดาผิดไปสามรอบก่อนจะเจอ ไม่ใช่เรื่องข้อมูลไม่ตรง ไม่ใช่ภูมิประเทศ และ `deploy()` ก็ทำงานเหมือนกันเป๊ะ (ลองสั่งวางใหม่จากข้อมูลชุดเดียวกัน ตรงกันทุกตัว)

**ตัวจริงคือ: หนึ่งในผู้เล่นเป็นบอท แล้วทุกเครื่องรันบอทของตัวเอง** บอทตัวเดียวกันจึงเดินคนละทางบนสี่จอ
บอทก็คือผู้เล่นคนหนึ่ง ต้องมีคนเล่นให้ — **เจ้าของห้องเป็นคนเล่นบอท** แล้วส่งการเดินขึ้นสายเหมือนคนจริง
นาฬิกาก็เหมือนกัน เจ้าของห้องเป็นคนตัดสินว่าหมดเวลา ไม่ใช่สี่เครื่องตัดสินกันคนละจังหวะ

**ตัวหมากไม่ได้หยุดตรงจุดเป๊ะ** — ท่าเดินเป็นตัวพาตัวหมากไป จบการเดินตรงไหนขึ้นกับจังหวะเฟรม
บนเครื่องเดียวไม่เห็น แต่ข้ามเครื่องคือ**ตัวเดียวกันอยู่คนละที่** แล้วเราวัดระยะยิงจากตำแหน่งนั้น
ยิงได้บนจอหนึ่ง ยิงไม่ได้บนอีกจอหนึ่ง — แก้ให้ลงตรงจุดที่กติกาอนุมัติเป๊ะ ๆ

**กองของบอทสุ่มด้วย `Math.random` แยกกันแต่ละเครื่อง** — กองของคนจริงส่งผ่านห้องเลยตรงกัน แต่บอทไม่มี pid ไม่ได้ส่งอะไร ตอนนี้กองบอทผูกกับ seed และเจ้าของห้องเป็นคนปั้นแล้วส่งไปพร้อมคำสั่งเริ่ม

## 3. ใครหลุด บอทเล่นแทน

ไม่ส่งสัญญาณเกิน **75 วินาที** = ถือว่าหลุด บอทรับช่วงกองนั้นต่อทันที บันทึกการรบขึ้นว่า "**… หลุดไป — บอทเล่นแทน**"

**ถ้าคนที่หลุดคือเจ้าของห้อง** ห้องจะยกหน้าที่ให้คนที่ยังอยู่คนแรก (เพราะเจ้าของห้องคือคนที่เล่นบอทกับคุมนาฬิกา ถ้าเขาหายแล้วไม่ส่งไม้ต่อ เกมจะค้าง)

## 4. Claude ลงเล่นเองได้แล้ว

เครื่องมือใหม่ 6 ตัวใน MCP — **Claude เป็นผู้เล่น ไม่ใช่กรรมการ**

| เครื่องมือ | ทำอะไร |
| --- | --- |
| `bt_list_tables` | ดูว่ามีโต๊ะไหนเปิดอยู่ |
| `bt_sit` | นั่งลงที่โต๊ะ ได้ pid มาเก็บไว้ |
| `bt_look` | ดูกระดาน · ตัวไหนของเรา · **ใครอยู่ในระยะยิงบ้าง ระยะเท่าไร** |
| `bt_move` | เดิน — เกินระยะถูกปฏิเสธพร้อมบอกตัวเลข |
| `bt_shoot` | ยิง — **ทอยลูกเต๋าที่เซิร์ฟเวอร์** ทุกคนเห็นผลเดียวกัน |
| `bt_end_turn` | จบตาของตัวเอง |

Claude ไม่มีเบราว์เซอร์ จึงรัน `deploy()` เองไม่ได้ — **เจ้าของห้องส่งภาพกระดานย่อขึ้นห้องทุกเทิร์น** Claude อ่านจากตรงนั้น

## ที่ยังไม่ได้ทำ

- **เดินทะลุกำแพง** — ปลายทางต้องว่าง แต่ระหว่างทางยังลากผ่านตึกได้ (ถ้าห้ามจะห้าม 38% ของทางเดิน และ 14 จาก 96 ตัวไม่เหลือทางไป)
- **เส้นสายตา** — ยิงทะลุตึกได้อยู่
- **ของพิเศษ / รูปแบบการรบ** จากภาพที่วาด ยังต้องออกแบบเนื้อหา
- ทุกโหมดจบที่ครบ 5 รอบ ไม่ค่อยมีใครล้มหมด — เรื่องความสนุก รอมินิตัดสิน
