ต้นทาง: มินิส่งโฟลเดอร์ `candlelight.rar` จากเครื่องตัวเองมาให้ดู พร้อมบอกว่า

## เกิดอะไรขึ้น

ผมตัวหมากที่ดีอยู่แล้ว **หายไปเพราะผมเอง** ไม่ใช่เพราะโค้ดพัง

ลำดับเหตุการณ์:

1. **ก.ย. (ก่อนหน้านี้)** — มีการเขียนผมแบบใหม่ "ก้อนทึบครอบกะโหลก" เสร็จ มินิดูแล้วอนุมัติ
   แล้ว deploy ขึ้น Worker ตรง ๆ แต่ **ไม่ได้ push ขึ้น GitHub** (โน้ตเก่าเขียนไว้ว่า
   "ahead origin 1 — ตั้งใจไม่ push เพราะ asset ไม่ได้ใช้ใน APK จะเสีย build เปล่า")
2. **ต่อมา** — มีการเขียนหัวกลมใหม่ใน commit `43b2245` โดยทำงานจากไฟล์ใน GitHub
   ซึ่งไม่มีผมชุดนั้น จึงได้หัวกลมแต่ไม่มีผม
3. **ตอนทำล็อกอินเกสต์** — ผมรัน `embed.py` ซึ่งอ่าน `board.html` จาก repo
   แล้วเขียนทับ `BOARD_HTML` ในเซิร์ฟเวอร์ **กระดานตัวดีที่อยู่บน Worker อย่างเดียวจึงถูกลบ**

วัดจาก git: `cd0bcab` มี `BOARD_HTML` 70,047 ตัวอักษร มีบล็อกผม · `feddcda` (งานเกสต์)
เหลือ 64,875 ตัวอักษร ไม่มีบล็อกผม

## ที่พังจริง (วัดแล้ว)

หัวหมากเปลี่ยนจาก**กล่อง**เป็น**ลูกกลม** แต่ของที่สวมหัวยังยึดพิกัดกล่องเดิม

| ของ | ก่อน (กล่อง) | หลัง (ลูกกลม) |
| --- | --- | --- |
| หัว | `hy1 = 1.38` ยอดแบน | `HCen 1.19, HR 0.21` ยอดโค้ง |
| ผม | แผ่นแบนวางบนยอดกล่อง → แนบ | แผ่นแบนลอยเหนือยอดโค้ง → **ลอย** |

วัดจากภาพที่เรนเดอร์จริง: แผ่นผมอยู่**เหนือหัว 6 พิกเซล** บนหัวสูง 44 พิกเซล — ลอยชัดเจน

แล้วปุ่มเลือกผมในแอพมี 5 แบบ (`short long tied shaved hood`) ซึ่งตรงกับ `LOOK_KEYS`
ในเซิร์ฟเวอร์อยู่แล้ว แต่กระดานเวอร์ชันเก่ารู้จักแค่ `bald short long ponytail braid mohawk curly bun`
→ **3 ใน 5 แบบไม่วาดอะไรเลย** นอกจากแผ่นลอย และ `shaved` ยังมีแผ่นผมโผล่บนหัวโล้น

หมวกทุกใบลอยด้วยเหตุผลเดียวกัน

## ที่แก้

ย้ายบล็อกผมจากไฟล์ในโฟลเดอร์ของมินิมาใส่ไฟล์ปัจจุบัน — ทำได้สะอาดเพราะของสองชุด
**ไม่ทับกันเลย**: ไฟล์เก่ามีบล็อกผมแต่ไม่มีลูกเต๋า ไฟล์ใหม่มีลูกเต๋าแต่ไม่มีบล็อกผม
และ `drawPawn` ของทั้งสองไฟล์เป็นตัวหมากเดียวกันทุกอย่าง (หัวกลม ไหล่ กระโปรง พิกัดเท่ากัน)

- เพิ่ม `emitHair` + ตัวช่วย (`polylineCut`, `arcPts`, `hairTint`, `shellQuad`, `sheetFace` …)
- สลับช่วงหัว/ผม/หน้า/หมวกใน `drawPawn` มาใช้ของชุดใหม่ ซึ่งตัดเส้นโครงกะโหลกตรงที่ผมบัง
  และซ่อนตา/หนวด/เคราเมื่อมองจากด้านหลังหัวหรือเมื่อใส่ฮู้ด
- ไม่แตะลูกเต๋า ไม่แตะแอพ ไม่แตะเซิร์ฟเวอร์ (คำที่แอพส่งตรงกับกระดานชุดใหม่อยู่แล้ว)

`HALIAS` แปลงค่าผมเก่าให้อัตโนมัติ (`ponytail braid bun` → `tied`, `bald` → `shaved`)
ตัวละครที่สร้างไว้แล้วจึงไม่พัง

## ตรวจแล้ว

| อะไร | ผล |
| --- | --- |
| ผมทั้ง 5 แบบ | แนบหัวทุกแบบ วัดแล้วทับกับหัว ไม่มีช่องว่าง |
| หมวกทั้ง 5 ใบ | อยู่บนหัว ฮู้ดบังผมถูกต้อง |
| เผ่าพันธุ์ 6 แบบ | หูเอลฟ์/เขาทีฟลิง/เคราคนแคระ โผล่พ้นผมถูกต้อง |
| กระดานจริง + ลูกเต๋า | 4 ตัวบนโต๊ะ ทอย d4–d20 ครบ ไม่มี JS error |
| ค่าเฟรม | 26.03 → 26.39 ms ต่อเฟรม (+1.4%) |
| ฝังลง worker.js | เปลี่ยนบรรทัดเดียว และถอดกลับมาตรงกับไฟล์ทุกไบต์ |

## ที่ยังไม่ได้ทำ

**เสื้อคลุมกับทรงลำตัว** — ตอนนี้เส้นเสื้อคลุมวาดที่ ±0.30–0.36 แต่ลำตัวกว้าง ±0.43
เส้นเลยจมอยู่ในตัว เห็นแค่เงาจาง ๆ

โน้ตเก่าบอกว่าเรื่องนี้ **ออกแบบเสร็จและมินิอนุมัติแล้ว** (`design-mock/outfit-body-test.html`
มินิบอกว่า "ใช้ได้เลย") แต่ยังไม่เคยขึ้น และต้องแก้ 3 ที่: กระดาน + `LOOK_KEYS` ในเซิร์ฟเวอร์
ต้องเพิ่ม `body` + แอพต้องมีปุ่มเลือกทรง (ออก APK ใหม่) — เป็นงานก้อนถัดไป ไม่ได้รวมมาในรอบนี้

## ที่มินิต้องทำ

1. merge PR ที่ `candlelight-table` (กระดาน) **และ** ที่ `candlelight-server` (ตัวที่ deploy)
2. ฝั่งเว็บ/คอมเห็นผลทันทีที่ deploy · ฝั่งมือถือต้องโหลด APK ใหม่ เพราะกระดานฝังอยู่ในแอพ
